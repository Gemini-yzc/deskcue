# DeskCue Windows 首版规格

## 目标与范围

基于 Stikly 的 Electron 与 Windows 桌面层实现，提供单窗口、本地保存的事项面板。开发范围已经由本次对话确认，包含 Windows EXE 与 GitHub 项目整理；本次不开发 macOS、不上传代码、不提供云同步。

## 行为与验收

- 固定顺序：每日关注、本人推进、等待外部；空分类保留标题。逐条编辑、优先级高/中/低、同级内移动排序。
- 条目默认单行，标题省略、点击看详情，优先级与时间同行；每日分类旁说明点击圆圈可结束当天提醒。名称只使用 DeskCue。
- 自动排序为分类、优先级、截止时间（每日以最后一天，其他以最后期限，无截止排最后），最后以创建时间兜底。同分类同优先级支持拖拽覆盖日期顺序，提供恢复自动排序；不再显示上下按钮。
- 八套配色和自选背景。图片复制到data/backgrounds，最多三张，按导入时间淘汰；导入第四张前提示确认，确认后删除最早副本，原始选中文件不动。重复导入同一内容不占新名额。等比铺满窗口、居中裁切，不拉伸、不留白。
- 本轮授权实现并打包 Windows 0.2.0，不自动推送或发布。旧数据版本1保持兼容；隐私约束覆盖Git提交、Release、Actions附件，任何个人data及其备份、日志、缓存、背景图都不得上传。
- 每日关注：起止日期、每日提醒时间；今日确认仅闭环当天，次日重新提醒。结束日过后未确认的最后一次仍保留提醒，确认后完成整项。
- 本人推进：可选最后期限；等待外部：可选跟进时间、最终期限、等待对象。等待事项转为本人推进时保留已经触发的提醒。
- 提醒可选关闭、相对期限提前若干分钟或直接指定日期时间。只选截止日期时由界面明确补全18:00。每条一个提醒时刻，触发后持续柔和闪耀至闭环，不设“知道了”或暂缓按钮。系统通知每个提醒周期只发一次；重启、休眠恢复后补检查。
- 事项完成或取消后停止提醒。取消保留至次年同日，闰日按次年2月末计算；超过保留期自动清除，恢复取消事项后重新参与提醒。
- 关闭窗口进入托盘；托盘退出才真正退出。提醒期间托盘与收起摘要保持可见提示，不抢输入焦点。桌面/普通/置顶三种模式。
- 数据在 EXE 同目录 data；开发版在项目 data。缓存、配置也写入 data。原版 Stikly 数据不自动读取或覆盖。
- 修改后立即由主进程原子落盘；每日备份保留最近7天，备份写出前过滤已过期取消事项。恢复备份后同样执行清理。无法读写时明确报错，损坏文件保留并从有效备份恢复。
- 输入验证、提醒计算、取消清理、排序和磁盘恢复通过 node:test；实际启动检查中文界面和 portable EXE。

## 技术栈与目录

Electron 31.7.7（上游锁定版本），CommonJS、原生 HTML/CSS/JavaScript；不引入运行时第三方依赖。src/domain.js 为纯业务逻辑，src/storage.js 负责存储，main.js 负责窗口与提醒，preload.js 为受限桥接，src/app.* 为界面，tests/ 为逻辑与存储测试。

## 命令

安装：npm ci；开发：npm start；检查：npm run check；测试：npm test；Windows便携EXE：npm run dist。

## 代码约定与边界

使用具名函数、camelCase、两空格缩进；业务函数接受显式时间参数以便验证，例如 reminderState(task, now)。所有来自界面的数据都在主进程验证；禁用 nodeIntegration，启用 contextIsolation，禁止外部导航。文档与行为同步；保留 MIT 与上游归属。不删除用户数据、不提交缓存、个人事项或凭据；超出已确认范围先沟通。
