# DeskCue v0.3.0

适用于 Windows 10/11 x64。下载便携 EXE 后可直接运行。ZIP 同时附带说明和许可证。

## 新功能

- 「定期关注」可以选择每周的某一天。启动时会补查错过的每周事项，提示保留到点击「我知道了」。
- 面板顶部显示事项时区的日期和时间。底部「修改时区」支持搜索地区、选 UTC 或跟随电脑。默认使用太平洋时间。
- 提醒、截止和跟进时间使用同一个事项时区。时区换算和夏令时处理可离线运行。

## 从 0.2.0 升级

1. 从系统托盘退出旧版，并备份旧 EXE 旁的整个 `data` 文件夹。
2. 把新版 EXE 放到该 `data` 旁边，再启动新版。如果换了文件夹，把 `data` 一起复制过去。
3. 首次启动会按东八区还原旧事项填写的日期和钟点，并将数据升级为版本 2。若要继续使用旧版，请使用升级前备份的版本 1 数据。

[下载 EXE、ZIP 和 SHA256 校验文件](https://github.com/Gemini-yzc/deskcue/releases/tag/v0.3.0)
