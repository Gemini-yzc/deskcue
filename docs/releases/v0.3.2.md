# DeskCue v0.3.2

适用于 Windows 10/11 x64。便携 EXE 可直接运行，ZIP 另附使用说明和许可证。

- **每周提醒可多选。** 在「定期关注」选择「每周」，勾选周一至周日中的一天或多天，再设置统一时间。只选周一到周五时，周末不会弹提醒。每个选中日独立确认。未确认的错过记录仍可在面板查看，补发通知等到下一选中日。
- **支持开机自启动。** 便携版首次运行默认登记当前 Windows 账户的登录自启。右键点击 DeskCue 托盘图标，可以在「开机自启动」中关闭或重新开启。

从 v0.3.1 升级时，先从托盘退出旧版，再把新版 EXE 放到原来的 `data/` 旁边启动。事项、单日提醒和设置可以直接读取。保存多日计划后，请用 v0.3.2 或以上版本打开同一份数据。若原来的自启或桌面快捷方式还指向旧版，可在新版中重新勾选自启，或更新桌面快捷方式。[升级与迁移步骤](https://github.com/Gemini-yzc/deskcue/blob/v0.3.2/README.md#更新便携版或迁移到新目录)
