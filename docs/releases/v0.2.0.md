# DeskCue v0.2.0 · Windows x64 便携版

下载 EXE 后放进可写文件夹，双击即可运行，无需安装或配置 Node.js。使用 ZIP 时请先完整解压。

## 本次更新

- 产品名称统一为 **DeskCue**，窗口右上角新增 GitHub 项目按钮。
- 事项默认压缩为 **34像素单行**，长标题省略，点击查看完整内容；低频操作放进更多菜单。
- 每日关注旁增加“点 ○：今日已做，停当天提醒”，当天确认后停止闪耀，次日重新提醒。
- 同分类先按优先级，再按截止时间由近到远排列，无截止排最后。同级内直接拖拽调整，支持恢复自动排序，移除上下按钮。
- 新增八套配色：暖灰绿、中性灰、冷灰蓝、沙岩米、雾粉、浅紫、薄荷、石墨。
- 自选背景复制到 `data/backgrounds`，最多三张；添加第四张前提示确认，确认后删除最早副本。重复图片不重复计数，原始文件不删除。
- 背景随窗口等比铺满、居中裁切，不拉伸、不留白。支持可解码的 PNG、JPG、WebP，单张不超过30MB。
- 补充个人数据禁传要求和全部开发活动的法律风险审查约束。

## 升级与数据

先右键托盘选择“退出 DeskCue”，再启动新版 EXE，**保留原 data 文件夹**。0.2.0 兼容旧版事项文件。旧实例未退出时，再次打开 EXE 会显示原来的窗口。

**下载包不包含 data、个人事项、自定义背景图片、备份或运行缓存。** 首次运行时在 EXE 旁创建 data，更新或迁移时由你保留和复制自己的数据。

18项业务与存储测试通过；本地便携版已验证单行显示、配色、背景裁切、排序、保存、重启和EXE旁数据目录。正式附件由同一版本的 GitHub Windows 构建生成，并再次检查校验值和ZIP白名单。

本版本仅支持 Windows 10/11 x64，macOS 暂未适配。EXE 未做商业代码签名；系统通知是否显示受 Windows 设置影响。基于 Stikly 二次开发，保留其MIT许可与原作者声明。
