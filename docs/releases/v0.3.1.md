# DeskCue v0.3.1

适用于 Windows 10/11 x64。便携 EXE 可以直接运行，ZIP 另附使用说明和许可证。

- 「定期关注」新增「无结束日期」，新建时默认勾选，每日或每周事项会持续重复。要设定结束日期时，取消勾选并填写「最后一天」。编辑已有事项时会回显保存的设置。
- 补充便携版升级、迁移和恢复备份的说明。

从 v0.3.0 升级时，从系统托盘退出旧版，替换 EXE 并保留同目录的 `data/`。如果换了目录，先备份目标目录已有的数据，再复制原来的 `data/`。详细步骤见 [README](https://github.com/Gemini-yzc/deskcue/blob/v0.3.1/README.md#更新便携版或迁移到新目录)。
